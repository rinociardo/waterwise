# Plant photos

Drop one image per **variety** here, named after the plant key. All 8 junipers
share `juniper.jpg`, all 3 hydrangeas share `hydrangea.jpg`, and so on — 12
files cover all 35 plants.

    cryptomeria.jpg      Cryptomeria japonica 'Radicans'
    thuja.jpg            Thuja x 'Green Giant'
    ilex-opaca.jpg       Ilex opaca 'Satyr Hill'
    chamaecyparis.jpg    Chamaecyparis nootkatensis 'Pendula'
    juniper.jpg          Juniperus scopulorum 'Skyrocket'
    hydrangea.jpg        Hydrangea paniculata 'Quick Fire'
    winterberry-f.jpg    Ilex verticillata 'Winter Red'
    winterberry-m.jpg    Ilex verticillata 'Southern Gentleman'
    viburnum.jpg         Viburnum nudum 'Winterthur'
    cornus.jpg           Cornus sericea (the variegated one you were sent)
    redbud.jpg           Cercis canadensis
    panicum.jpg          Panicum virgatum 'North Wind'

They render as 44px thumbnails on Today and 72px on Plants, cropped square, so
centre the plant and don't worry about framing. **Resize to about 400x400 and
save at moderate JPEG quality** — these get cached for offline use, and a
handful of 4MB phone photos would make the app slow to install and painful on
mobile data.

Missing files are not an error. The app hides any image that fails to load, so
you can add them one at a time.

To change a filename or point at a different image, edit the `photo:` field for
that variety in `js/plants.js`.
